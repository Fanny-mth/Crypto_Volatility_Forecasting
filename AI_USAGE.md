AI tools were used during this project as support tools.

They were mainly used for:
- clarifying theoretical concepts (e.g. GARCH models and LSTM architectures),
- helping debug Python errors when implementation issues arose,
- discussing high-level implementation ideas and code structure,
- improving the clarity and wording of explanations in the report.

All core implementation decisions, model development, experiments, and result analysis were carried out by me.

AI assistance was used to overcome specific difficulties, validate certain approaches, and improve code readability, but not to automatically generate the final solution.
